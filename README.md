A React web application for exploring Pokémon data through a responsive, API-driven interface. Inspired by the visual design of Nintendo DS-era Pokémon games, PokeView combines nostalgic aesthetics with modern frontend development practices.

## Technical Highlights

- Built with **React**, HTML, and CSS
- Integrated with the **PokéAPI** to retrieve real-time Pokémon data
- Implemented dynamic search and client-side state management
- Designed a responsive interface with light and dark themes
- Created smooth UI animations and transitions to enhance user experience
- Applied component-based architecture for reusable and maintainable code

## Data Source

Pokémon data is provided by the official **PokéAPI**.
